"# QuizWay" 
A modern, responsive Quiz Website built using **HTML**, **CSS**, and **JavaScript**. This project provides an interactive quiz experience with a clean UI and dynamic functionality, making it suitable for beginners learning frontend development.



## 📌 Features

- ✅ Interactive quiz interface
- ✅ Start Quiz screen
- ✅ Multiple-choice questions
- ✅ 15-second countdown timer
- ✅ Automatic next question on timeout
- ✅ Real-time score tracking
- ✅ Progress bar
- ✅ Correct & incorrect answer highlighting
- ✅ Quiz result page
- ✅ Restart quiz functionality
- ✅ Fully responsive design
- ✅ Clean and beginner-friendly code

## 🎮 How to Play

1. Click the **Start Quiz** button.
2. Read each question carefully.
3. Select one of the available answers.
4. Your score updates automatically for correct answers.
5. Click **Next** to continue.
6. If the timer reaches **0**, the quiz automatically moves to the next question.
7. After completing all questions, your final score is displayed.
8. Click **Restart Quiz** to play again.
